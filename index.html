活动 01 · Vitalik 主旨演讲 · 1/2

不让每个节点都重复做重活

Vitalik Buterin · 以太坊联合创始人

Vitalik 讨论的核心不是单纯提高交易速度，而是改变分工：把签名和证明的重计算分散到网络边缘，再让链上验证聚合结果。

主要讲了什么

  • 安全功能也有成本。抗量子签名、隐私证明和自定义验证规则，通常比普通签名更大、更难验证。若全部直接放到链上，安全与隐私越强，费用和处理负担就可能越高。
  • 交易与证明材料分开。交易说明“要做什么”，依赖声明说明“执行前必须证明什么”。用户仍广播完整签名或证明，但链上不必保存每份庞大的原始材料。
  • 在交易池中提前聚合。节点接收包含交易与证明的“信封”，把多份证明聚成一份，再继续传播。聚合不是等交易上链后才做，而是在等待打包时就开始。
  • 重点扩容验证，而非所有计算。签名和证明验证可以大规模并行；账户余额变化、交易顺序等业务逻辑仍需正确处理。讲者将这种分工类比为面向验证的专门分片。

理解补充

可以把它理解成：许多人分别检查材料，再交出一份可被核验的总证明，而不是让每一位链上验证者重新检查所有附件。这里依靠密码学证明，不是相信某位汇总人的承诺。

理解时注意

这是研发方案及其预期效果，不是已经上线的功能公告。聚合可以降低重复验证的负担，但计算本身仍然需要资源。

活动 01 · Vitalik 主旨演讲 · 2/2

这项改动会让哪些事更便宜？

Vitalik Buterin · 以太坊联合创始人

演讲希望降低的，是“证明一件事正确”的成本。由此受益的，不只有隐私交易，也包括账户验证、L2 和客户端计算。

可能带来的变化

  • 隐私和抗量子验证更容易使用。若昂贵签名和证明可以共享聚合成本，采用这些技术的额外费用有望下降；用户不必在可用性和更强的保护之间做过于昂贵的选择。
  • L2 有望更频繁提交证明。现在逐次提交证明有固定成本，交易量较少时尤其明显。降低这一成本，可能让 L2 更及时地向以太坊提交证明，而不是长时间攒批次。
  • 把重计算放到客户端。不适合在 EVM 中直接运行的计算，可以在用户端完成，再提交证明。链上负责核验结果，不必亲自重算全部过程。
  • RISC-V 是被讨论的表达方式。讲者谈到用更简洁的指令体系表达待证明计算。这不等于 EVM 已被替换，更不等于所有以太坊应用要立即改写。
  • 开发者可以参与底层优化。讲者提及早期模拟、相关测试网、可试代码及算法竞赛。参与方向包括验证方案、改进证明算法和降低计算开销。

这一场最值得记住

一句话记住：不是让计算凭空消失，而是重新安排谁来计算、何时计算，以及链上到底需要检查多少东西。

理解时注意

聚合方案并不自动消除所有隐私泄露、共识或账户安全风险；“证明正确”“保护隐私”“抵抗量子攻击”仍需分别满足条件。

活动 02 · 远程问答

从预测结果，走向实际用途

Vitalik Buterin 与主持

Vitalik 的问答把技术话题落到三个问题：预测市场除了“猜输赢”还能做什么，为什么在 L1 做应用，以及中国开发者怎样参与。

嘉宾直接回答的重点

  • 预测市场应帮助管理风险。嘉宾肯定产品更易使用和竞争增加，但认为社会价值仍未充分展开。他尤其重视针对具体事件的风险对冲，而不只是围绕热门事件交易。
  • 条件市场可辅助比较方案。讨论的是“如果某事件发生，另一结果的概率如何”。它可汇集人们对不同选择后果的判断，但市场价格本身不能直接证明因果关系。
  • L1 的优势是少一些依赖。嘉宾把 L1 描述为中间环节和基础设施依赖相对更少的地方，并期待扩容使应用费用下降。这里的“更简单可靠”是比较性判断，不是零风险保证。
  • AI 可降低学习与研究门槛。开发者可参加带自动校验的算法优化竞赛，也可用 AI 理解复杂协议。AI 帮助入门不意味着其答案无需验证。

理解补充

例如一家组织担心特定事件导致收入下降，预测市场的支付结构可能成为其风险管理工具。这是帮助理解“对冲”的例子，不是现场提供的交易方案。

理解时注意

问答后，主持进一步谈到开源 AI、集中化风险与防御技术。这属于主持的延伸解读，与 Vitalik 的直接回答分开理解。

活动 03 · 主办说明与社区对谈

好社区，也需要可持续的支持

Bruce 与主持

这一环节先说明活动的写作与公共叙事动机，再讨论免费教育、开源建设如何获得持续资金，而不是只靠一时热情。

两个相连的小环节

  • 主办说明：让圈外看见更多面向。主持介绍一个认同密码朋克的写作组织，希望用更好的表达，让公众看到技术、开源与公共物品建设，而不只看到少数投机或猎奇故事。
  • 社区介绍：免费教育也是基础设施。Bruce 介绍教育、技术交流、资助和线下空间等实践，并用不同代际建设者之间的联系解释活动的“文艺复兴”主题。
  • 主持强调补上商业能力。主持以跨生态经历为例，认为理解资金、产品和商业运作，有助于把长期价值做出来。这是个人观察，并非对不同生态的客观排名。
  • Bruce 强调形成支持循环。公共物品若缺少后续资金，容易在最初资助结束后中断。他同时欢迎其他生态的开发者参与，不把社区认同理解为封闭边界。
  • “复兴”意味着重新长出应用。主持用“东北文学”的失落与底蕴作比喻，希望已有技术和社区积累能承接新的应用；这是一种文化表达，而非市场预测。

这一场最值得记住

双方的共同问题是：怎样让有公共价值的事情长期做下去。现场提出了方向，但没有给出一个已经验证成功的资助闭环。

理解时注意

Bruce 强调，个人对项目或代币的看法不代表主办方。讨论的重点是社区建设与可持续支持，而不是项目推荐。

活动 04 · 回望圆桌 · 1/3

早期理想，与后来经历的市场周期

巨蟹、高素质蓝领、Conflux 嘉宾及主持

这场圆桌没有给“加密危机”下一个统一诊断，而是让不同代际的从业者回顾：最初为什么进入，后来哪些想法被现实改变。

第一组问题：当年被什么打动？

  • 通用智能合约打开新想象。巨蟹认为，相比单纯转账，以太坊试图提供可以编程的通用平台，更具吸引力。他也强调创始人与开发者的理想主义、坚持和协作。
  • 早期并非人人都立即相信。蓝领承认，最初更容易理解具体的转账或交易功能，对这种抽象平台及其能否落地存在怀疑。讨论保留了不确定性，而非把历史写成必然成功。

术语速查 1 / 3 · 链与验证

先把这些技术名词分清

以下是帮助阅读的通用解释，不表示每个词都在现场被完整讲授，也不用于确认某项提案已经上线。

L1 / L2深入理解 ↗
L1 是基础链；L2 是建立在基础链之上的扩展系统。不同 L2 的证明、数据和退出机制不同，不能只凭“二层”标签判断安全性。
Gas / EVM深入理解 ↗
Gas 是计量链上计算与资源使用的单位，不是固定人民币价格。EVM 是以太坊执行智能合约的运行环境。
交易池 / 递归与聚合证明深入理解 ↗
交易池存放等待打包的交易。递归证明可以验证其他证明；聚合则把多份验证工作汇入更少的证明。二者常配合，但不是任何“打包”都具有同样的安全性质。
账户抽象 / 框架化交易深入理解 ↗
账户抽象让账户验证与操作更可编程；框架化交易是把不同处理步骤更明确地组织起来的交易设计。它们不是“所有钱包自动安全或匿名”的开关。
EIP / RISC-V深入理解 ↗
EIP 是以太坊改进提案，存在提案不等于主网已经采用。RISC-V 是指令集架构，可用于表达计算；讨论使用它不等于已经全面替换 EVM。
Agent / Keeper / 反应式合约深入理解 ↗
Agent 是可按目标和权限执行任务的软件代理；keeper 通常监控条件并提交交易；反应式合约围绕事件触发逻辑。自动化仍需处理权限、费用、失败和外部依赖。

术语速查 2 / 3 · 密码学

签名、保密、证明，不是一回事

选择技术前，先问目标：要证明谁授权、隐藏输入，还是证明某段计算真的正确？这些目标可以组合，但不能互相替代。

私钥 / 数字签名深入理解 ↗
私钥是签署指令的秘密材料，不能与普通网站密码混同。有效签名可验证授权关系，却不能判断用户是否被诱导，也不会自动隐藏交易内容。
零知识证明（ZK）深入理解 ↗
在不泄露约定秘密的前提下证明某个陈述成立。它不自动确保输入是真实世界的事实，也不自动让整条链匿名。
SNARK / STARK深入理解 ↗
两类常见证明系统家族，各自还有许多具体方案。透明性、证明大小、验证成本和安全假设需看具体设计，不能仅凭缩写判断完整系统安全。
全同态加密（FHE）深入理解 ↗
让计算方在不直接看到明文的情况下计算密文，授权方解密结果。主要解决数据机密性，不单独保证受托方诚实执行了所有计算。
隐私集合求交（PSI）深入理解 ↗
帮助两方找到约定的共同元素，例如匹配通讯录和已注册用户，同时保护交集之外的信息。泄露多少信息取决于具体协议。
抗量子安全 / 形式化验证深入理解 ↗
抗量子安全关注足够强量子攻击下的安全假设。形式化验证用数学方法检查实现是否满足明确规格；它仍依赖规格正确、模型适用，不能证明一切现实风险都不存在。

术语速查 3 / 3 · 应用与组织

金融和社区词汇，怎样理解

这些概念经常一起出现，但“上链”“开放”“有积分”都不足以单独说明一个组织或产品已经有效运转。

公共物品 / 密码朋克深入理解 ↗
公共物品在经济学中通常具有非排他性和非竞争性，开放知识与开源基础设施常与之相关。密码朋克强调以密码学和工具维护隐私与自主性，不只是赛博朋克审美。
DAO / 公共金库 / 社区积分深入理解 ↗
DAO 借助规则和数字工具协作治理；公共金库管理共同资源；积分可记录贡献和兑换资格。三者仍需责任主体、兑现规则和争议处理，不自动产生公平。
预测市场 / 条件市场 / 对冲深入理解 ↗
预测市场交易与事件结果相关的头寸；条件市场关注特定条件下的结果；对冲则试图抵消既有风险。市场价格不直接证明因果，也不等于保证赚到钱。
稳定币 / 资产代币化深入理解 ↗
稳定币以相对某种资产保持稳定价值为目标；代币化用链上记录表达资产或权利。二者仍受储备、法律权利、发行者和兑付机制影响。
DeFi / 自托管 / 白标深入理解 ↗
DeFi 通常指基于智能合约提供金融功能。自托管强调用户控制密钥；白标是由一方提供技术、另一方以自身品牌交付。不同标签不能替代具体的安全和责任分析。
开源模型 / 本地 AI深入理解 ↗
公开权重、开放源代码、公开训练数据并不是同一件事，要看许可证与开放范围。本地 AI 在用户或组织控制的设备上运行，可能改善数据控制，但仍需检查软件和数据处理流程。
